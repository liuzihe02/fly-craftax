# M5 Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watch the fly play: a scrubbable viewer with the game frame (fly sprite), the brain lighting up over real soma positions, the six readout signals, and the internal meters, rendered offline as PNG frames with a slider page and a GIF.

**Architecture:** `flycraftax/viewer.py` draws five fly sprites, injects them into Craftax's cached 64 px textures so the standard renderer shows a fly, projects soma positions to 2-D, and composes one matplotlib panel per action. `scripts/make_viewer.py` runs the zero-shot fly (full wiring, readout policy) for 300 actions with `make_step` eagerly, keeping each window's spike counts, writes `outputs/viewer/frames/NNNN.png`, `outputs/viewer/index.html` (plain JS slider and play button over the frames), and `outputs/viewer.gif`.

**Tech Stack:** jax, craftax, numpy, matplotlib, imageio (all pinned).

**Spec:** `tracker.md` (Spec > Viewer; Milestones > M5). Reading of the spec for this milestone: "panels" and "fly as sprite" are delivered; "real-time interactive using the existing libraries" is delivered as a scrubbable offline page over pre-rendered frames, since the brain runs at 0.38x realtime per action; a live navis 3-D view is a follow-up.

## Global Constraints

- Game panel: `make_craftax_pixel_renderer(64)` after replacing `full_map_player_textures` and `full_map_player_textures_alpha` in `load_all_textures()[64]` with the fly sprites padded exactly as `constants.py` pads the player textures (`pad_pixels = (3 * 64, 4 * 64)`), index order left, right, up, down, sleep.
- Fly sprites: 16 x 16 RGBA drawn procedurally in numpy (dark body along the facing axis, a head dot at the facing end, two lighter translucent wings, the sleep variant with wings folded and a small `z`), upscaled to 64 x 64 with nearest-neighbour.
- Brain panel: soma positions from `data/body-annotations.feather` `somaLocation` (126,115 of the 146,271 population have one); project to the two axes that show the two optic lobes at the left and right extremes (check by eye: the projection with the widest bimodal spread). Background: all somata in light grey, size 1. Foreground: neurons that spiked in the current window, coloured by spike count, size 3. Readout group cells drawn as larger outlined markers.
- Signals panel: the six z-scores as a horizontal bar chart with the `z_floor` line and the chosen action highlighted. Meters panel: health, food, drink, energy as four bars 0..9 and the action string.
- Rollout: `full` wiring, `readout` policy, batch 1, 300 actions, `PRNGKey(0)`, run eagerly with `make_step` so the per-window `brain.counts` are available without storing a 146k x 300 raster on the device.
- Outputs under `outputs/` (gitignored): `viewer/frames/0000.png` ..., `viewer/index.html`, `viewer.gif` (every frame, 10 fps, half resolution). Figure size 16 x 9 inches at 80 dpi.
- Minimal code; fast tests only for the sprite and composition functions with synthetic inputs; the rollout is a script.

```python
# flycraftax/viewer.py
"""Offline viewer: fly sprite in the game render, brain activity over soma positions, readout and meters."""
from pathlib import Path

import jax.numpy as jnp
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from craftax.craftax_classic.constants import BLOCK_PIXEL_SIZE_HUMAN, OBS_DIM, load_all_textures
from craftax.craftax_classic.renderer import make_craftax_pixel_renderer

from flycraftax.env import ACTIONS
from flycraftax.readout import SIGNALS

BODY, WING, HEAD = (40, 30, 30, 255), (200, 220, 255, 140), (20, 20, 20, 255)


def _draw(facing_up, sleeping):
    """16x16 RGBA fly facing up (row 0 is the head end); callers rotate/flip."""
    s = np.zeros((16, 16, 4), np.uint8)
    yy, xx = np.mgrid[:16, :16]
    body = ((yy - 8.5) / 5.0) ** 2 + ((xx - 7.5) / 2.2) ** 2 <= 1.0
    if sleeping:
        wings = ((yy - 9) / 4.0) ** 2 + ((xx - 7.5) / 3.2) ** 2 <= 1.0
    else:
        wings = (((yy - 9) / 3.5) ** 2 + ((xx - 3.5) / 3.0) ** 2 <= 1.0) | (((yy - 9) / 3.5) ** 2 + ((xx - 11.5) / 3.0) ** 2 <= 1.0)
    s[wings] = WING
    s[body] = BODY
    head = ((yy - 3.5) / 1.6) ** 2 + ((xx - 7.5) / 1.6) ** 2 <= 1.0
    s[head] = HEAD
    if sleeping:
        s[1, 12:15] = s[3, 12:15] = (255, 255, 255, 255); s[2, 13] = (255, 255, 255, 255)   # a small z
    return s


def fly_sprites():
    up = _draw(True, False)
    return np.stack([np.rot90(up, 1), np.rot90(up, -1), up, up[::-1], _draw(True, True)])   # left, right, up, down, sleep


def make_fly_renderer():
    bps = BLOCK_PIXEL_SIZE_HUMAN
    tex = load_all_textures()[bps]
    sprites = fly_sprites().repeat(bps // 16, axis=1).repeat(bps // 16, axis=2)
    pad = ((OBS_DIM[0] // 2) * bps, (OBS_DIM[1] // 2) * bps)
    padded = jnp.array([jnp.pad(s, ((pad[0], pad[0]), (pad[1], pad[1]), (0, 0))) for s in sprites])
    tex["full_map_player_textures"] = padded[..., :3].astype(jnp.float32)
    tex["full_map_player_textures_alpha"] = jnp.repeat(padded[..., 3:4].astype(jnp.float32) / 255, 3, axis=3)
    return make_craftax_pixel_renderer(bps)


def soma_xy(conn, data_dir=Path("data")):
    ann = pd.read_feather(data_dir / "body-annotations.feather", columns=["bodyId", "somaLocation"]).set_index("bodyId")
    loc = ann.somaLocation.reindex(conn.body_id)
    xyz = np.array([l if l is not None else [np.nan] * 3 for l in loc.values], np.float32)
    return xyz[:, :2]   # adjust the axis pair once so the optic lobes sit left and right; record the choice here


def compose(frame64, counts, xy, groups, z, action, meters, z_floor):
    fig, ax = plt.subplots(1, 3, figsize=(16, 9), dpi=80, gridspec_kw=dict(width_ratios=[1.1, 1.3, 0.6]))
    ax[0].imshow(np.asarray(frame64) / 255.0); ax[0].set_axis_off(); ax[0].set_title("Craftax")
    ok = ~np.isnan(xy[:, 0])
    ax[1].scatter(xy[ok, 0], xy[ok, 1], s=1, c="#dddddd", linewidths=0)
    hot = ok & (counts > 0)
    ax[1].scatter(xy[hot, 0], xy[hot, 1], s=3, c=counts[hot], cmap="inferno", vmin=0, vmax=max(1, np.percentile(counts[hot], 95) if hot.any() else 1), linewidths=0)
    for name, g in groups.items():
        gg = g[ok[g]]
        ax[1].scatter(xy[gg, 0], xy[gg, 1], s=40, facecolors="none", edgecolors="cyan" if counts[gg].sum() == 0 else "red", linewidths=1)
    ax[1].set_aspect("equal"); ax[1].set_axis_off(); ax[1].set_title(f"{int(hot.sum())} neurons spiking this window")
    ax[2].barh(range(6), z, color=["red" if i == np.argmax(z) and z[i] >= z_floor else "grey" for i in range(6)])
    ax[2].axvline(z_floor, color="k", ls="--"); ax[2].set_yticks(range(6)); ax[2].set_yticklabels(SIGNALS); ax[2].set_xlim(-3, 5)
    ax[2].set_title(f"action: {ACTIONS[int(action)]}")
    ins = ax[2].inset_axes([0.0, -0.45, 1.0, 0.3])
    names = ["health", "food", "drink", "energy"]
    ins.bar(names, [meters[k] for k in names], color=["crimson", "orange", "dodgerblue", "gold"]); ins.set_ylim(0, 9)
    fig.tight_layout()
    fig.canvas.draw()
    img = np.asarray(fig.canvas.buffer_rgba())[..., :3].copy()
    plt.close(fig)
    return img
```

```python
# scripts/make_viewer.py
"""Run the zero-shot fly for 300 actions and render a scrubbable viewer."""
from pathlib import Path

import imageio.v2 as imageio
import jax
import jax.numpy as jnp
import numpy as np

from flycraftax.brain import BrainParams
from flycraftax.data import load_connectome
from flycraftax.drive import build_drive
from flycraftax.env import base_state, make_env
from flycraftax.loop import build_agent, init_carry, make_step
from flycraftax.readout import load_readout
from flycraftax.retina import build_retina
from flycraftax.viewer import compose, make_fly_renderer, soma_xy

HTML = """<!doctype html><title>fly-craftax viewer</title>
<style>body{font-family:sans-serif;margin:1em}img{max-width:100%%}</style>
<img id=f src="frames/0000.png"><br>
<input id=s type=range min=0 max=%d value=0 style="width:80%%"> <button id=p>play</button> <span id=t>0</span>
<script>
const n=%d,f=document.getElementById('f'),s=document.getElementById('s'),t=document.getElementById('t');let timer=null;
function show(i){f.src='frames/'+String(i).padStart(4,'0')+'.png';s.value=i;t.textContent=i;}
s.oninput=()=>show(+s.value);
document.getElementById('p').onclick=()=>{if(timer){clearInterval(timer);timer=null;return;}timer=setInterval(()=>show((+s.value+1)%%n),100);};
</script>"""


def main(n_actions=300, out=Path("outputs/viewer")):
    conn = load_connectome()
    readout, cfg = load_readout(conn)
    drive = build_drive(conn, build_retina(conn), cfg["max_hz"], lamina_mv=cfg["lamina_mv"])
    agent = build_agent(conn, drive, readout, BrainParams(w_syn=cfg["w_syn"]))
    env = make_env(1)
    render = jax.jit(make_fly_renderer())
    xy = soma_xy(conn)
    key, k0 = jax.random.split(jax.random.PRNGKey(0))
    carry = init_carry(agent, env, k0, 1) + (None,)
    step = make_step(agent, env, obs0=carry[0])
    (out / "frames").mkdir(parents=True, exist_ok=True)
    frames = []
    for i, k in enumerate(jax.random.split(key, n_actions)):
        st = base_state(carry[1])
        frame64 = np.asarray(render(jax.tree.map(lambda x: x[0], st)))
        carry, log = step(carry, k)
        counts = np.asarray(carry[2].counts[0]) if False else None   # counts are reset per window inside step; see note
        img = compose(frame64, np.asarray(log["counts"])[0], xy, readout.groups, np.asarray(log["z"])[0], int(log["action"][0]),
                      dict(health=int(st.player_health[0]), food=int(st.player_food[0]), drink=int(st.player_drink[0]), energy=int(st.player_energy[0])),
                      readout.z_floor)
        imageio.imwrite(out / "frames" / f"{i:04d}.png", img)
        frames.append(img[::2, ::2])
        if i % 50 == 0:
            print(i, flush=True)
    (out / "index.html").write_text(HTML % (n_actions - 1, n_actions))
    imageio.mimsave(out.parent / "viewer.gif", frames, duration=0.1)
    print(out / "index.html", out.parent / "viewer.gif")


if __name__ == "__main__":
    main()
```

Per-window counts: `make_step` calls `reset_counts` before the window and `reset_envs` after the env step, so `carry[2].counts` after the step still holds this window's counts unless the env finished. Add to `make_step`'s log a `counts` entry only when a `keep_counts=True` keyword is given (the log dict must keep a stable structure; this script passes `keep_counts=True`), and drop the placeholder line above. Under `lax.scan` in M3/M4 this keyword stays False so nothing large is logged.
