# M3 Zero-Shot Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the loop with the fixed DN-to-action mapping, calibrate the drive so the output groups are readable, and evaluate the fly against ablation controls so any behaviour can be attributed to input and wiring rather than to the readout.

**Architecture:** `flycraftax/readout.py` maps six DN group rates to six signals and one action through z-scores against a random-policy baseline stored in `flycraftax/readout_norm.json`. `flycraftax/loop.py` runs env, drive, brain window, readout, and env step as one `lax.scan` over actions with ablation and policy chosen statically. `scripts/calibrate.py` sweeps drive gain and synapse weight under a random policy and writes the norm file. `scripts/eval_zero_shot.py` runs the conditions and writes a JSON, a figure, and a GIF.

**Tech Stack:** jax 0.11.1, craftax 1.6.1, numpy, matplotlib, imageio (already pinned).

**Spec:** `tracker.md` (Spec > I/O mapping > Outputs, Spec > Brain, Milestones > M3). M2 finding that motivates Task 1: under retina plus interoception drive at 100 Hz and `w_syn = 0.275`, DNp09, MDN, and DNa02_R never fired over 40 random actions; MN9 and the FB6/FB7 group only responded once the thirst deficit began (`docs/plans/2026-09-10-m2-env.md`, M2 Task 7 report).

## Global Constraints

- Output mapping (spec): forward DNp09; backward MDN; turn DNa02 + DNa01 left-minus-right; do MN9; sleep FB6/FB7 tangentials. Action = argmax of signals, noop when all below a floor.
- Signals, in this order: `forward` = mean DNp09 rate; `backward` = mean MDN; `turn_left` = mean(DNa01_L, DNa02_L) minus mean(DNa01_R, DNa02_R); `turn_right` = minus `turn_left`; `do` = mean MN9; `sleep` = mean of FB6* and FB7* cells. Rates in Hz over one `STEPS_PER_ACTION` window.
- Floor: z = (signal - mean) / std with mean and std measured on a random-policy rollout under the calibrated config; std is floored at one spike per window per group cell (`5.0 / group_size` Hz at 200 steps of 0.1 ms) so a silent signal cannot become hypersensitive; action = argmax z, noop unless max z >= `z_floor = 1.0`. Recorded as a controller ruling: some per-signal gain is unavoidable because group sizes range from 2 to 140 cells.
- Calibration grid: `max_hz` in (100, 200, 300) and `w_syn` in (0.275, 0.44). 0.44 is 0.275 divided by 0.627, the fraction of synaptic mass the threshold-5 cut keeps (spec: recalibrate the constant if the threshold changes). Selection rule: iterate `w_syn` ascending then `max_hz` ascending and pick the first config where at least four of the six raw signals have non-zero std over the rollout and the mean fraction of neurons active per window is below 0.25. If none qualifies, pick the config with the most non-zero signals under the active-fraction cap and say so. The controller ratifies the pick before Task 3.
- Ablations: `full`; `black` (frame zeros, internal state still driven); `disconnected` (all drive zero); `shuffled` (edge targets permuted with seed 0, in-degree distribution preserved). Policy: `readout` or `random`. The `random` baseline in evaluation is `full` wiring with the `random` policy.
- Brain state persists across actions and resets per env on `done` via `reset_envs`; `STEPS_PER_ACTION = 200`.
- Evaluation: per condition batch 8 envs, 2,000 actions cap, seed 0; report survival length (actions until the first `done`, 2,000 if none), achievements per type over the episode, action histogram, mean reward per action. Outputs to `outputs/` (gitignored); a two-line summary and the calibration pick go into the tracker under M3.
- Minimal code; tests on synthetic rates run fast; anything with the real brain or env is `slow`.

```python
# flycraftax/readout.py
"""Fixed DN-to-action readout: six signals, z-scored against a random-policy baseline."""
import json
from dataclasses import dataclass
from pathlib import Path

import jax.numpy as jnp
import numpy as np

from flycraftax.env import BACKWARD, DO, FORWARD, NOOP, SLEEP, TURN_LEFT, TURN_RIGHT

SIGNALS = ("forward", "backward", "turn_left", "turn_right", "do", "sleep")
SIGNAL_ACTION = np.array([FORWARD, BACKWARD, TURN_LEFT, TURN_RIGHT, DO, SLEEP], np.int32)
GROUP_NAMES = ("forward", "backward", "turn_l", "turn_r", "do", "sleep")
NORM_PATH = Path(__file__).with_name("readout_norm.json")
SPIKE_HZ = 5.0   # one spike in a 200-step window of 0.1 ms


def readout_groups(conn):
    def turn(side):
        return np.concatenate([conn.index(types=["DNa01"], side=side), conn.index(types=["DNa02"], side=side)])
    return {
        "forward": conn.index(types=["DNp09"]),
        "backward": conn.index(types=["MDN"]),
        "turn_l": turn("L"),
        "turn_r": turn("R"),
        "do": conn.index(types=["MN9"]),
        "sleep": np.concatenate([conn.index(type_prefix="FB6"), conn.index(type_prefix="FB7")]),
    }


@dataclass
class Readout:
    """Unhashable: close over it, never pass it as a static jit argument."""
    groups: dict
    mean: np.ndarray
    std: np.ndarray
    z_floor: float = 1.0


def group_rates(groups, rates):
    return {k: rates[:, g].mean(axis=1) for k, g in groups.items()}


def signals(groups, rates):
    r = group_rates(groups, rates)
    turn = r["turn_l"] - r["turn_r"]
    return jnp.stack([r["forward"], r["backward"], turn, -turn, r["do"], r["sleep"]], axis=1)


def act(readout, rates):
    z = (signals(readout.groups, rates) - readout.mean) / readout.std
    best = jnp.argmax(z, axis=1)
    action = jnp.where(z.max(axis=1) >= readout.z_floor, jnp.asarray(SIGNAL_ACTION)[best], NOOP)
    return action, z


def std_floor(groups):
    n = {k: len(v) for k, v in groups.items()}
    turn = min(n["turn_l"], n["turn_r"])
    return SPIKE_HZ / np.array([n["forward"], n["backward"], turn, turn, n["do"], n["sleep"]], np.float32)


def save_readout(path, max_hz, w_syn, mean, std, z_floor=1.0):
    Path(path).write_text(json.dumps({
        "max_hz": float(max_hz), "w_syn": float(w_syn), "z_floor": float(z_floor),
        "mean": [float(x) for x in mean], "std": [float(x) for x in std],
    }, indent=1))


def load_readout(conn, path=NORM_PATH):
    cfg = json.loads(Path(path).read_text())
    groups = readout_groups(conn)
    std = np.maximum(np.array(cfg["std"], np.float32), std_floor(groups))
    return Readout(groups, np.array(cfg["mean"], np.float32), std, cfg["z_floor"]), cfg
```

```python
# flycraftax/loop.py
"""Closed loop: obs and state -> drive -> brain window -> readout -> env step, as one scan over actions."""
from dataclasses import dataclass

import jax
import jax.numpy as jnp
import numpy as np

from flycraftax.brain import (
    STEPS_PER_ACTION, BrainParams, build_weights, init_state, rate_hz, reset_counts, reset_envs, rfc_steps, run_window,
)
from flycraftax.drive import Drive, drive_rates, kick_prob
from flycraftax.env import ACTIONS, base_state
from flycraftax.readout import Readout, act, signals

ABLATIONS = ("full", "black", "disconnected", "shuffled")
POLICIES = ("readout", "random")


@dataclass
class Agent:
    """Unhashable: close over it, never pass it as a static jit argument."""
    W: object
    rfc: jax.Array
    p: BrainParams
    drive: Drive
    readout: Readout
    n: int
    n_steps: int = STEPS_PER_ACTION


def build_agent(conn, drive, readout, p=BrainParams(), ablation="full", seed=0):
    post = np.random.default_rng(seed).permutation(conn.post) if ablation == "shuffled" else conn.post
    W = build_weights(conn.n, conn.pre, post, conn.signed_count(), p)
    return Agent(W, rfc_steps(conn.n, drive.idx, p), p, drive, readout, conn.n)


def rollout(agent, env, key, n_actions, batch, ablation="full", policy="readout", keep_frames=False):
    assert ablation in ABLATIONS and policy in POLICIES
    params = env.default_params
    key, k0 = jax.random.split(key)
    obs, env_state = env.reset(k0, params)
    silence = jnp.ones(agent.n)

    def step(carry, k):
        obs, env_state, brain = carry
        k_brain, k_act, k_env = jax.random.split(k, 3)
        st = base_state(env_state)
        obs_in = jnp.zeros_like(obs) if ablation == "black" else obs
        rates_in = drive_rates(agent.drive, obs_in, st)
        if ablation == "disconnected":
            rates_in = jnp.zeros_like(rates_in)
        kp = kick_prob(agent.drive, rates_in, agent.n, agent.p)
        brain = run_window(agent.W, agent.rfc, agent.p, reset_counts(brain), kp, silence, k_brain, agent.n_steps)
        rates = rate_hz(brain.counts, agent.n_steps, agent.p)
        action, z = act(agent.readout, rates)
        if policy == "random":
            action = jax.random.randint(k_act, (batch,), 0, len(ACTIONS))
        obs2, env_state2, reward, done, _ = env.step(k_env, env_state, action, params)
        brain = reset_envs(brain, done, agent.p)
        log = dict(
            action=action, reward=reward, done=done, sig=signals(agent.readout.groups, rates), z=z,
            active=(brain.counts > 0).mean(axis=1), achievements=st.achievements,
            health=st.player_health, food=st.player_food, drink=st.player_drink, energy=st.player_energy,
        )
        if keep_frames:
            log["frame"] = obs[0]
        return (obs2, env_state2, brain), log

    keys = jax.random.split(key, n_actions)
    _, logs = jax.lax.scan(step, (obs, env_state, init_state(agent.n, batch, agent.p)), keys)
    return logs
```

Note: `active` is read after `reset_envs`, so a finished env reports 0 for that action; acceptable.

```python
# scripts/calibrate.py
"""Sweep drive gain and synapse weight under a random policy; write the readout norm file."""
import json
from pathlib import Path

import jax
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

from flycraftax.brain import BrainParams
from flycraftax.data import load_connectome
from flycraftax.drive import build_drive
from flycraftax.env import make_env
from flycraftax.loop import build_agent, rollout
from flycraftax.readout import NORM_PATH, SIGNALS, Readout, readout_groups, save_readout, std_floor
from flycraftax.retina import build_retina

GRID = [(w, hz) for w in (0.275, 0.44) for hz in (100.0, 200.0, 300.0)]


def main(n_actions=80, batch=4, out=Path("outputs/calibration.png")):
    conn = load_connectome()
    retina = build_retina(conn)
    groups = readout_groups(conn)
    blank = Readout(groups, np.zeros(6, np.float32), std_floor(groups))
    env = make_env(batch, reset_ratio=batch)
    rows = []
    for w_syn, max_hz in GRID:
        agent = build_agent(conn, build_drive(conn, retina, max_hz), blank, BrainParams(w_syn=w_syn))
        logs = rollout(agent, env, jax.random.PRNGKey(0), n_actions, batch, policy="random")
        sig = np.asarray(logs["sig"]).reshape(-1, 6)
        row = dict(w_syn=w_syn, max_hz=max_hz, mean=sig.mean(0).tolist(), std=sig.std(0).tolist(),
                   nonzero=int((sig.std(0) > 0).sum()), active=float(np.asarray(logs["active"]).mean()))
        rows.append(row)
        print(f"w_syn={w_syn:.3f} max_hz={max_hz:4.0f}  nonzero signals={row['nonzero']}  active={row['active']:.3f}  "
              + "  ".join(f"{s}={m:.2f}" for s, m in zip(SIGNALS, row["mean"])))
    ok = [r for r in rows if r["nonzero"] >= 4 and r["active"] < 0.25]
    pick = ok[0] if ok else max((r for r in rows if r["active"] < 0.25), key=lambda r: r["nonzero"], default=rows[0])
    print("pick:", pick["w_syn"], pick["max_hz"], "qualified" if ok else "best available")
    save_readout(NORM_PATH, pick["max_hz"], pick["w_syn"], pick["mean"], pick["std"])
    out.parent.mkdir(exist_ok=True)
    json.dump(rows, open(out.with_suffix(".json"), "w"), indent=1)
    fig, ax = plt.subplots(1, 2, figsize=(12, 4))
    for i, s in enumerate(SIGNALS):
        ax[0].plot([r["mean"][i] for r in rows], marker="o", label=s)
    ax[0].set_xticks(range(len(rows))); ax[0].set_xticklabels([f"{r['w_syn']}/{r['max_hz']:.0f}" for r in rows], rotation=45)
    ax[0].set_ylabel("mean signal (Hz)"); ax[0].legend(ncol=2); ax[0].set_title("signals vs w_syn/max_hz")
    ax[1].bar(range(len(rows)), [r["active"] for r in rows]); ax[1].set_xticks(range(len(rows)))
    ax[1].set_xticklabels([f"{r['w_syn']}/{r['max_hz']:.0f}" for r in rows], rotation=45); ax[1].set_ylabel("active fraction")
    fig.tight_layout(); fig.savefig(out, dpi=110); print(out)


if __name__ == "__main__":
    main()
```

```python
from flycraftax.readout import load_readout
from flycraftax.retina import build_retina

CONDITIONS = [("full", "readout"), ("black", "readout"), ("disconnected", "readout"), ("shuffled", "readout"), ("full", "random")]


def summarise(logs, n_actions):
    done = np.asarray(logs["done"])                        # (T, B)
    first = np.where(done.any(0), done.argmax(0) + 1, n_actions)
    ach = np.asarray(logs["achievements"])                 # (T, B, 22) pre-step
    unlocked = np.stack([ach[min(f, n_actions - 1), b] for b, f in enumerate(first)])   # (B, 22)
    actions = np.asarray(logs["action"])
    hist = np.bincount(actions.ravel(), minlength=len(ACTIONS)) / actions.size
    return dict(survival=first.tolist(), achievements=unlocked.sum(0).tolist(),
                action_hist=hist.tolist(), reward=float(np.asarray(logs["reward"]).mean()))


def main(n_actions=2000, batch=8, out=Path("outputs")):
    conn = load_connectome()
    readout, cfg = load_readout(conn)
    drive = build_drive(conn, build_retina(conn), cfg["max_hz"])
    p = BrainParams(w_syn=cfg["w_syn"])
    env = make_env(batch, reset_ratio=batch)
    results = {}
    for ablation, policy in CONDITIONS:
        name = f"{ablation}/{policy}"
        agent = build_agent(conn, drive, readout, p, ablation=ablation)
        logs = rollout(agent, env, jax.random.PRNGKey(0), n_actions, batch, ablation=ablation, policy=policy)
        results[name] = summarise(logs, n_actions)
        r = results[name]
        print(f"{name:22s} survival {np.mean(r['survival']):7.1f}  reward/action {r['reward']:+.4f}  "
              f"achievements {sum(r['achievements'])}  actions " + " ".join(f"{a[:2]}={h:.2f}" for a, h in zip(ACTIONS, r["action_hist"])))
    out.mkdir(exist_ok=True)
    json.dump(dict(config=cfg, results=results), open(out / "zero_shot.json", "w"), indent=1)

    names = list(results)
    fig, ax = plt.subplots(1, 3, figsize=(16, 4.5))
    for i, n in enumerate(names):
        ax[0].scatter([i] * batch, results[n]["survival"], s=14)
    ax[0].bar(range(len(names)), [np.mean(results[n]["survival"]) for n in names], alpha=0.4)
    ax[0].set_xticks(range(len(names))); ax[0].set_xticklabels(names, rotation=30, ha="right"); ax[0].set_ylabel("actions survived")
    idx = [a.value for a in (Achievement.COLLECT_WOOD, Achievement.EAT_COW, Achievement.COLLECT_SAPLING, Achievement.COLLECT_DRINK,
                             Achievement.DEFEAT_ZOMBIE, Achievement.DEFEAT_SKELETON, Achievement.WAKE_UP)]
    bottom = np.zeros(len(names))
    for j in idx:
        vals = np.array([results[n]["achievements"][j] for n in names])
        ax[1].bar(range(len(names)), vals, bottom=bottom, label=Achievement(j).name.lower()); bottom += vals
    ax[1].set_xticks(range(len(names))); ax[1].set_xticklabels(names, rotation=30, ha="right"); ax[1].set_ylabel("achievements (8 envs)"); ax[1].legend(fontsize=7)
    for i, n in enumerate(names):
        ax[2].plot(results[n]["action_hist"], marker="o", label=n)
    ax[2].set_xticks(range(len(ACTIONS))); ax[2].set_xticklabels(ACTIONS, rotation=30, ha="right"); ax[2].set_ylabel("action frequency"); ax[2].legend(fontsize=7)
    fig.tight_layout(); fig.savefig(out / "zero_shot.png", dpi=110)

    agent = build_agent(conn, drive, readout, p)
    logs = rollout(agent, env, jax.random.PRNGKey(1), 300, batch, keep_frames=True)
    frames = (np.asarray(logs["frame"]) * 255).astype(np.uint8).repeat(4, axis=1).repeat(4, axis=2)
    imageio.mimsave(out / "zero_shot.gif", list(frames), duration=0.1)
    print(out / "zero_shot.png", out / "zero_shot.gif")


if __name__ == "__main__":
    main()
```
