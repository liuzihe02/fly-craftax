# M3 Zero-Shot Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the loop with the fixed DN-to-action mapping, give the lamina a resting rate so vision can propagate, calibrate the drive so the output groups are readable, and evaluate the fly against ablation controls so any behaviour can be attributed to input and wiring rather than to the readout.

**Architecture:** `flycraftax/brain.py` gains an optional per-neuron tonic `bias` (mV per step) so lamina monopolar cells fire at rest and photoreceptor inhibition modulates them. `flycraftax/readout.py` maps six DN group rates to six signals and one action through z-scores against a random-policy baseline stored in `flycraftax/readout_norm.json`. `flycraftax/loop.py` runs env, drive, brain window, readout, and env step as one `lax.scan` over actions with ablation and policy chosen statically. `scripts/calibrate.py` sweeps the lamina bias and the synapse weight under a random policy and writes the norm file. `scripts/eval_zero_shot.py` runs the conditions and writes a JSON, a figure, and a GIF.

**Tech Stack:** jax 0.11.1, craftax 1.6.1, numpy, matplotlib, imageio (already pinned).

**Spec:** `tracker.md` (Spec > I/O mapping, Spec > Brain, Milestones > M3). Why Task 1 exists: the M2 whole-branch review measured that all 2,182 driven photoreceptors are histaminergic (sign -1, 12,458 output edges, all inhibitory) and all 21 ER5 cells are inhibitory, so in the zero-baseline Shiu model neither vision nor fatigue can excite anything. The M2 rollout confirmed it: only the excitatory hunger and thirst channels reached the readout groups. Controller ruling (pending owner approval, recorded in the tracker): lamina cells L1 to L5 receive a tonic bias so they have a resting rate that light, via photoreceptor inhibition, reduces. That is the real lamina physiology (L1/L2 depolarise in the dark, hyperpolarise to light).

## Global Constraints

- Output mapping (spec): forward DNp09; backward MDN; turn DNa02 + DNa01 left-minus-right; do MN9; sleep FB6/FB7 tangentials. Action = argmax of signals, noop when all below a floor.
- Signals, in this order: `forward` = mean DNp09 rate; `backward` = mean MDN; `turn_left` = mean(DNa01_L, DNa02_L) minus mean(DNa01_R, DNa02_R); `turn_right` = minus `turn_left`; `do` = mean MN9; `sleep` = mean of FB6* and FB7* cells. Rates in Hz over one `STEPS_PER_ACTION` window.
- Floor: z = (signal - mean) / std with mean and std measured on a random-policy rollout under the calibrated config; std is floored at one spike per window per group cell (`SPIKE_HZ / group_size` with `SPIKE_HZ = 1000 / (STEPS_PER_ACTION * dt_ms)` = 50 Hz at 200 steps of 0.1 ms) so a silent signal cannot become hypersensitive; action = argmax z, noop unless max z >= `z_floor = 1.0`. Ruling: some per-signal gain is unavoidable because group sizes range from 2 to 140 cells.
- Tonic bias: `step`/`run_window` accept `bias` of shape `(N,)` in mV added to `v` once per step for non-refractory neurons, default none (zero). With `b = exp(-dt/t_mbr)` the resting depolarisation is `bias / (1 - b)`, about 200 x bias at dt 0.1 ms, and a cell fires periodically once that exceeds the 7 mV gap: bias 0.04 gives about 23 Hz, 0.06 about 55 Hz, 0.10 about 93 Hz (before refractory). The oracle tests must stay bit-identical with `bias` unset.
- Lamina set: `type` in `L1, L2, L3, L4, L5`. `build_drive(conn, retina, max_hz=100.0, lamina_mv=0.0)` produces `drive.bias (N,)` with `lamina_mv` at those cells and 0 elsewhere. Lamina cells are not kicked, so they keep their refractory period.
- Calibration grid: `lamina_mv` in (0.04, 0.06, 0.10) and `w_syn` in (0.275, 0.44), `max_hz` fixed at 100. 0.44 is 0.275 divided by 0.627, the synaptic-mass fraction the threshold-5 cut keeps (spec: recalibrate the constant if the threshold changes). Selection rule: iterate `w_syn` ascending then `lamina_mv` ascending; pick the first config where at least four of the six raw signals have non-zero std over the rollout, the mean fraction of neurons active per window is below 0.25, and the mean L1 rate under a black frame exceeds the mean L1 rate under real frames (light must reduce lamina firing). If none qualifies, pick the config with the most non-zero signals under the active-fraction cap and say so. The controller ratifies the pick before Task 5.
- Ablations: `full`; `black` (frame zeros: photoreceptors silent, lamina at its resting rate); `static` (the rollout's first frame held for every step, so vision carries no information about the world); `disconnected` (all kicks zero, bias kept); `shuffled` (edge targets permuted with seed 0, in-degree distribution preserved). Policy: `readout` or `random`. The `random` baseline in evaluation is `full` wiring with the `random` policy.
- Brain state persists across actions and resets per env on `done` via `reset_envs`; `STEPS_PER_ACTION = 200`.
- Evaluation: per condition batch 8 envs, 2,000 actions cap, seed 0; report survival length (actions until the first `done`, 2,000 if none), achievements per type over the episode, action histogram, mean reward per action. Outputs to `outputs/` (gitignored); a two-line summary and the calibration pick go into the tracker under M3.
- Minimal code; tests on synthetic rates run fast; anything with the real brain or env is `slow`.

```python
# flycraftax/readout.py
"""Fixed DN-to-action readout: six signals, z-scored against a random-policy baseline."""
import json
from dataclasses import dataclass
from pathlib import Path

import jax.numpy as jnp
import numpy as np

from flycraftax.env import BACKWARD, DO, FORWARD, NOOP, SLEEP, TURN_LEFT, TURN_RIGHT

SIGNALS = ("forward", "backward", "turn_left", "turn_right", "do", "sleep")
SIGNAL_ACTION = np.array([FORWARD, BACKWARD, TURN_LEFT, TURN_RIGHT, DO, SLEEP], np.int32)
GROUP_NAMES = ("forward", "backward", "turn_l", "turn_r", "do", "sleep")
NORM_PATH = Path(__file__).with_name("readout_norm.json")
SPIKE_HZ = 1000.0 / (STEPS_PER_ACTION * BrainParams().dt_ms)   # 50 Hz: one spike in one window


def readout_groups(conn):
    def turn(side):
        return np.concatenate([conn.index(types=["DNa01"], side=side), conn.index(types=["DNa02"], side=side)])
    return {
        "forward": conn.index(types=["DNp09"]),
        "backward": conn.index(types=["MDN"]),
        "turn_l": turn("L"),
        "turn_r": turn("R"),
        "do": conn.index(types=["MN9"]),
        "sleep": np.concatenate([conn.index(type_prefix="FB6"), conn.index(type_prefix="FB7")]),
    }


@dataclass
class Readout:
    """Unhashable: close over it, never pass it as a static jit argument."""
    groups: dict
    mean: np.ndarray
    std: np.ndarray
    z_floor: float = 1.0


def group_rates(groups, rates):
    return {k: rates[:, g].mean(axis=1) for k, g in groups.items()}


def signals(groups, rates):
    r = group_rates(groups, rates)
    turn = r["turn_l"] - r["turn_r"]
    return jnp.stack([r["forward"], r["backward"], turn, -turn, r["do"], r["sleep"]], axis=1)


def act(readout, rates):
    z = (signals(readout.groups, rates) - readout.mean) / readout.std
    best = jnp.argmax(z, axis=1)
    action = jnp.where(z.max(axis=1) >= readout.z_floor, jnp.asarray(SIGNAL_ACTION)[best], NOOP)
    return action, z


def std_floor(groups):
    n = {k: len(v) for k, v in groups.items()}
    turn = min(n["turn_l"], n["turn_r"])
    return SPIKE_HZ / np.array([n["forward"], n["backward"], turn, turn, n["do"], n["sleep"]], np.float32)


def save_readout(path, max_hz, w_syn, lamina_mv, mean, std, z_floor=1.0):
    Path(path).write_text(json.dumps({
        "max_hz": float(max_hz), "w_syn": float(w_syn), "lamina_mv": float(lamina_mv), "z_floor": float(z_floor),
        "mean": [float(x) for x in mean], "std": [float(x) for x in std],
    }, indent=1))


def load_readout(conn, path=NORM_PATH):
    cfg = json.loads(Path(path).read_text())
    groups = readout_groups(conn)
    std = np.maximum(np.array(cfg["std"], np.float32), std_floor(groups))
    return Readout(groups, np.array(cfg["mean"], np.float32), std, cfg["z_floor"]), cfg
```

```python
# flycraftax/loop.py
"""Closed loop: obs and state -> drive -> brain window -> readout -> env step, as one scan over actions."""
from dataclasses import dataclass

import jax
import jax.numpy as jnp
import numpy as np

from flycraftax.brain import (
    STEPS_PER_ACTION, BrainParams, build_weights, init_state, rate_hz, reset_counts, reset_envs, rfc_steps, run_window,
)
from flycraftax.drive import Drive, drive_rates, kick_prob
from flycraftax.env import ACTIONS, base_state
from flycraftax.readout import Readout, act, signals

ABLATIONS = ("full", "black", "static", "disconnected", "shuffled")
POLICIES = ("readout", "random")


@dataclass
class Agent:
    """Unhashable: close over it, never pass it as a static jit argument."""
    W: object
    rfc: jax.Array
    p: BrainParams
    drive: Drive
    readout: Readout
    n: int
    n_steps: int = STEPS_PER_ACTION


def build_agent(conn, drive, readout, p=BrainParams(), ablation="full", seed=0):
    post = np.random.default_rng(seed).permutation(conn.post) if ablation == "shuffled" else conn.post
    W = build_weights(conn.n, conn.pre, post, conn.signed_count(), p)
    return Agent(W, rfc_steps(conn.n, drive.idx, p), p, drive, readout, conn.n)


def rollout(agent, env, key, n_actions, batch, ablation="full", policy="readout", keep_frames=False):
    assert ablation in ABLATIONS and policy in POLICIES
    params = env.default_params
    key, k0 = jax.random.split(key)
    obs0, env_state = env.reset(k0, params)
    silence = jnp.ones(agent.n)
    bias = jnp.asarray(agent.drive.bias)
    l1 = agent.drive.lamina_l1

    def step(carry, k):
        obs, env_state, brain = carry
        k_brain, k_act, k_env = jax.random.split(k, 3)
        st = base_state(env_state)
        obs_in = {"black": jnp.zeros_like(obs), "static": obs0}.get(ablation, obs)
        rates_in = drive_rates(agent.drive, obs_in, st)
        if ablation == "disconnected":
            rates_in = jnp.zeros_like(rates_in)
        kp = kick_prob(agent.drive, rates_in, agent.n, agent.p)
        brain = run_window(agent.W, agent.rfc, agent.p, reset_counts(brain), kp, silence, k_brain, agent.n_steps, bias=bias)
        rates = rate_hz(brain.counts, agent.n_steps, agent.p)
        action, z = act(agent.readout, rates)
        if policy == "random":
            action = jax.random.randint(k_act, (batch,), 0, len(ACTIONS))
        obs2, env_state2, reward, done, _ = env.step(k_env, env_state, action, params)
        log = dict(
            action=action, reward=reward, done=done, sig=signals(agent.readout.groups, rates), z=z,
            active=(brain.counts > 0).mean(axis=1), lamina=rates[:, l1].mean(axis=1), achievements=st.achievements,
            health=st.player_health, food=st.player_food, drink=st.player_drink, energy=st.player_energy,
        )
        if keep_frames:
            log["frame"] = obs[0]
        brain = reset_envs(brain, done, agent.p)
        return (obs2, env_state2, brain), log

    keys = jax.random.split(key, n_actions)
    _, logs = jax.lax.scan(step, (obs0, env_state, init_state(agent.n, batch, agent.p)), keys)
    return logs
```

```python
"""Sweep lamina bias and synapse weight under a random policy; write the readout norm file."""
import json
from pathlib import Path

import jax
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

from flycraftax.brain import BrainParams
from flycraftax.data import load_connectome

from flycraftax.loop import build_agent, rollout

from flycraftax.retina import build_retina

MAX_HZ = 100.0
GRID = [(w, mv) for w in (0.275, 0.44) for mv in (0.04, 0.06, 0.10)]


def main(n_actions=80, batch=4, out=Path("outputs/calibration.png")):
    conn = load_connectome()
    retina = build_retina(conn)
    groups = readout_groups(conn)
    blank = Readout(groups, np.zeros(6, np.float32), std_floor(groups))
    env = make_env(batch)
    rows = []
    for w_syn, mv in GRID:
        drive = build_drive(conn, retina, MAX_HZ, lamina_mv=mv)
        agent = build_agent(conn, drive, blank, BrainParams(w_syn=w_syn))
        full = rollout(agent, env, jax.random.PRNGKey(0), n_actions, batch, policy="random")
        black = rollout(agent, env, jax.random.PRNGKey(0), 20, batch, ablation="black", policy="random")

        row = dict(w_syn=w_syn, lamina_mv=mv, mean=sig.mean(0).tolist(), std=sig.std(0).tolist(),
                   nonzero=int((sig.std(0) > 0).sum()), active=float(np.asarray(full["active"]).mean()),
                   l1_full=float(np.asarray(full["lamina"]).mean()), l1_black=float(np.asarray(black["lamina"]).mean()))
        rows.append(row)
        print(f"w_syn={w_syn:.3f} mv={mv:.2f}  nonzero={row['nonzero']}  active={row['active']:.3f}  "
              f"L1 full/black {row['l1_full']:.1f}/{row['l1_black']:.1f} Hz  "
              + "  ".join(f"{s}={m:.2f}" for s, m in zip(SIGNALS, row["mean"])))
    ok = [r for r in rows if r["nonzero"] >= 4 and r["active"] < 0.25 and r["l1_black"] > r["l1_full"]]
    pick = ok[0] if ok else max((r for r in rows if r["active"] < 0.25), key=lambda r: r["nonzero"], default=rows[0])
    print("pick:", pick["w_syn"], pick["lamina_mv"], "qualified" if ok else "best available")
    save_readout(NORM_PATH, MAX_HZ, pick["w_syn"], pick["lamina_mv"], pick["mean"], pick["std"])
    out.parent.mkdir(exist_ok=True)
    json.dump(rows, open(out.with_suffix(".json"), "w"), indent=1)
    labels = [f"{r['w_syn']}/{r['lamina_mv']}" for r in rows]
    fig, ax = plt.subplots(1, 3, figsize=(16, 4))
    for i, s in enumerate(SIGNALS):
        ax[0].plot([r["mean"][i] for r in rows], marker="o", label=s)
    ax[0].set_xticks(range(len(rows))); ax[0].set_xticklabels(labels, rotation=45); ax[0].set_ylabel("mean signal (Hz)"); ax[0].legend(ncol=2)
    ax[1].bar(range(len(rows)), [r["active"] for r in rows]); ax[1].set_xticks(range(len(rows))); ax[1].set_xticklabels(labels, rotation=45); ax[1].set_ylabel("active fraction")
    ax[2].plot([r["l1_full"] for r in rows], marker="o", label="L1 real frames"); ax[2].plot([r["l1_black"] for r in rows], marker="s", label="L1 black frame")
    ax[2].set_xticks(range(len(rows))); ax[2].set_xticklabels(labels, rotation=45); ax[2].set_ylabel("Hz"); ax[2].legend()
    fig.tight_layout(); fig.savefig(out, dpi=110); print(out)


if __name__ == "__main__":
    main()
```

```python
# scripts/eval_zero_shot.py
"""Zero-shot fly versus ablation controls: survival, achievements, actions; JSON, figure, GIF."""
import json
from pathlib import Path

import imageio.v2 as imageio
import jax
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
from craftax.craftax_classic.constants import Achievement

from flycraftax.brain import BrainParams
from flycraftax.data import load_connectome
from flycraftax.drive import build_drive
from flycraftax.env import ACTIONS, make_env
from flycraftax.loop import build_agent, rollout
from flycraftax.readout import load_readout
from flycraftax.retina import build_retina

CONDITIONS = [("full", "readout"), ("black", "readout"), ("static", "readout"), ("disconnected", "readout"),
              ("shuffled", "readout"), ("full", "random")]
SURVIVAL = (Achievement.COLLECT_WOOD, Achievement.EAT_COW, Achievement.COLLECT_SAPLING, Achievement.COLLECT_DRINK,
            Achievement.DEFEAT_ZOMBIE, Achievement.DEFEAT_SKELETON, Achievement.WAKE_UP)


def summarise(logs, n_actions):
    done = np.asarray(logs["done"])
    first = np.where(done.any(0), done.argmax(0) + 1, n_actions)
    ach = np.asarray(logs["achievements"])
    unlocked = np.stack([ach[min(f, n_actions - 1), b] for b, f in enumerate(first)])
    actions = np.asarray(logs["action"])
    hist = np.bincount(actions.ravel(), minlength=len(ACTIONS)) / actions.size
    return dict(survival=first.tolist(), achievements=unlocked.sum(0).tolist(),
                action_hist=hist.tolist(), reward=float(np.asarray(logs["reward"]).mean()))


def main(n_actions=2000, batch=8, out=Path("outputs")):
    conn = load_connectome()
    readout, cfg = load_readout(conn)
    drive = build_drive(conn, build_retina(conn), cfg["max_hz"], lamina_mv=cfg["lamina_mv"])
    p = BrainParams(w_syn=cfg["w_syn"])
    env = make_env(batch)
    results = {}
    for ablation, policy in CONDITIONS:
        name = f"{ablation}/{policy}"
        agent = build_agent(conn, drive, readout, p, ablation=ablation)
        logs = rollout(agent, env, jax.random.PRNGKey(0), n_actions, batch, ablation=ablation, policy=policy)
        results[name] = r = summarise(logs, n_actions)
        print(f"{name:22s} survival {np.mean(r['survival']):7.1f}  reward/action {r['reward']:+.4f}  "
              f"achievements {sum(r['achievements'])}  actions " + " ".join(f"{a[:2]}={h:.2f}" for a, h in zip(ACTIONS, r["action_hist"])), flush=True)
    out.mkdir(exist_ok=True)
    json.dump(dict(config=cfg, results=results), open(out / "zero_shot.json", "w"), indent=1)

    names = list(results)
    fig, ax = plt.subplots(1, 3, figsize=(17, 4.5))
    for i, n in enumerate(names):
        ax[0].scatter([i] * batch, results[n]["survival"], s=14)
    ax[0].bar(range(len(names)), [np.mean(results[n]["survival"]) for n in names], alpha=0.4)
    ax[0].set_xticks(range(len(names))); ax[0].set_xticklabels(names, rotation=30, ha="right"); ax[0].set_ylabel("actions survived")
    bottom = np.zeros(len(names))
    for a in SURVIVAL:
        vals = np.array([results[n]["achievements"][a.value] for n in names])
        ax[1].bar(range(len(names)), vals, bottom=bottom, label=a.name.lower()); bottom += vals
    ax[1].set_xticks(range(len(names))); ax[1].set_xticklabels(names, rotation=30, ha="right"); ax[1].set_ylabel(f"achievements ({batch} envs)"); ax[1].legend(fontsize=7)
    for n in names:
        ax[2].plot(results[n]["action_hist"], marker="o", label=n)
    ax[2].set_xticks(range(len(ACTIONS))); ax[2].set_xticklabels(ACTIONS, rotation=30, ha="right"); ax[2].set_ylabel("action frequency"); ax[2].legend(fontsize=7)
    fig.tight_layout(); fig.savefig(out / "zero_shot.png", dpi=110)

    agent = build_agent(conn, drive, readout, p)
    logs = rollout(agent, env, jax.random.PRNGKey(1), 300, batch, keep_frames=True)
    frames = (np.asarray(logs["frame"]) * 255).astype(np.uint8).repeat(4, axis=1).repeat(4, axis=2)
    imageio.mimsave(out / "zero_shot.gif", list(frames), duration=0.1)
    print(out / "zero_shot.png", out / "zero_shot.gif")


if __name__ == "__main__":
    main()
```
